# Security

Please report security issues privately. Do not open a public issue or pull request with the details.

Use [GitHub's private vulnerability reporting](https://github.com/kabeerx9/baton/security/advisories/new) on this repository.

Include what you have: the affected commit, the endpoint or flow, what an attacker gains and the privilege they need, and a proof of concept.

Fixes land on `main`. There are no supported older releases.
